# Sprint_7
# Автоматизация тестирования API для сервиса доставки самокатов

Проект представляет собой набор автоматизированных тестов для проверки REST API сервиса управления курьерами и заказами.

## Стек технологий
- **Python 3.9+**
- **Pytest** - фреймворк для тестирования
- **Allure** - система отчетности
- **Requests** - работа с HTTP-запросами
- **Poetry/Pip** - управление зависимостями

## Основные функции тестирования
1. Создание и удаление курьеров
2. Авторизация в системе
3. Создание и отмена заказов
4. Проверка списка заказов
5. Параметризованные тесты граничных значений
6. Негативные сценарии

Установить зависимости:
pip install -r requirements.txt

Стандартный запуск всех тестов:
pytest tests/ --alluredir=allure-results
Запуск с генерацией Allure-отчета:
allure serve allure-results

Sprint_7/
